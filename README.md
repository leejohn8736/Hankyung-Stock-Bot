# 📈 Hankyung Real-time Stock News RSS Bot (GitHub Actions)

한국경제 RSS 피드를 실시간으로 모니터링하여, 뉴스 속 호재 키워드가 포함된 종목 중 **영업이익이 증가하고 유보율이 500% 이상인 우량 일반 종목**을 코스피 1개, 코스닥 1개씩 선별하여 매 12분마다 텔레그램으로 자동 발송해 주는 서버리스(Serverless) 파이썬 봇입니다.

## 📂 프로젝트 구조

 # 📈 실시간 키워드 뉴스 주식 수혜종목 모니터링 봇 (Hankyoung-Stock-Bot)

네이버 실시간 뉴스 검색을 통해 지정한 핵심 테마 키워드(반도체, AI, 방산 등)를 24시간 감시하고, KRX 종목 마스터와 네이버 금융 재무제표를 분석하여 **코스피/코스닥 일반주 및 잡주(우선주/스팩) 각 1개씩 총 4개 종목**을 실시간으로 발송하는 자동화 봇입니다.

 

## ⚙️ 주요 기능 및 로직

1. **실시간 뉴스 크롤링 (`news_crawler.py`)**
   - RSS 피드 방식 대신 네이버 뉴스 실시간 검색을 통해 최신 뉴스를 다각도로 수집합니다.
   - 설정된 핵심 키워드 매칭 점수를 계산하여 가장 호재가 뚜렷한 기사를 선별합니다.

2. **KRX 종목 및 재무 필터링 (`krx_filter.py`)**
   - 코스피 및 코스닥 전 종목을 대상으로 일반주와 잡주(우선주, 스팩 등)를 구분하여 로드합니다.
   - 일반주는 네이버 금융 재무제표(영업이익 흑자 및 유보율 300% 이상)를 엄격히 검증하며, 잡주는 뉴스 호재를 바탕으로 유연하게 선별합니다.

3. **총 4개 종목 엄선 및 텔레그램 발송 (`main.py`)**
   - **코스피 일반주 1개 / 코스피 잡주 1개 / 코스닥 일반주 1개 / 코스닥 잡주 1개** (총 4선)를 선정하여 전송합니다.
   - 조건에 맞는 종목이 없더라도 봇의 생체 신호(Heartbeat) 유지를 위해 **"현재 조건 충족 종목 없음"** 알림을 텔레그램으로 보냅니다.

4. **운영 시간 및 자동화**
   - **운영 시간:** KST 기준 매일 **새벽 04:00 ~ 자정 24:00**
   - **실행 주기:** GitHub Actions 및 외부 웹훅을 통해 12분마다 자동 실행됩니다.
